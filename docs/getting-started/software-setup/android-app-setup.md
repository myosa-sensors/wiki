# BLE App for Android

## Prerequisite

Need to have Master Code in MYOSA Motherboard to App to work. So if you have uploaded any other code on your own then you have to upload the master code in MYOSA motherboard first. If you don’t know how to upload Master code, please refer to our **[Uploading Master Code](/docs/getting-started/uploading-master-code/)** section.

After uploading the **Master Code** in the MYOSA motherboard download the MYOSA base.apk from [here](https://github.com/myosa-sensors/android-apk/raw/refs/heads/main/base.apk). After downloading the apk in your android device, install it and then go through the below video for setup and basic walkaround of the app.
